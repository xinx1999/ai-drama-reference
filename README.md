# AI 短剧参考库 · 风格 / 人物 / 服装 / 姿势

纯静态单页应用，直接打开 `index.html` 即可使用，无需构建。

## 功能

- **风格**：46 种风格对照图，每种含中文名 / 英文名关键词标签与中英双提示词，图片为本地 jpg。
- **人物**：1499 张人像，图片直连线上图库，可按分区、发长、51 种发型筛选。
- **服装**：3224 套服装，图片直连线上图库，可按现实/二次元、分类、单品/颜色标签筛选。
- **姿势**：288 组姿势 × 5 角度，支持素体白模/深度图切换，可按体系、动作分类、视角筛选。
- **配方 dock**：从四类各选一个素材，点「提示词」弹框可分别复制中文/英文提示词，也可一键随机。

## 数据来源

- 风格图由本地 FreeVideo（qwen-image-2.1-turbo）生成。
- 人物 / 服装 / 姿势图来自 [anhao/ai-pose-gallery-zh](https://github.com/anhao/ai-pose-gallery-zh)（线上直链），版权归原作者所有。

## 本地使用

双击 `index.html` 即可。人物/服装/姿势页图片需要联网加载，风格页离线可用。

## GitHub Pages 部署

1. 用这个目录作为仓库根目录推送到 GitHub。
2. 仓库 Settings → Pages → Source 选择 `main` 分支 `/ (root)`。
3. 访问 `https://你的用户名.github.io/仓库名/`。

`.nojekyll` 已包含，确保静态资源正常加载。
